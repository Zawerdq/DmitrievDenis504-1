# Испытания на реальном роботе

Три уровня проверки отмечаются раздельно: **эмулятор** (ПК/контейнер), **стенд** (робот
на подставке, гусеницы в воздухе или сняты), **пол/трасса**. Пустая клетка — не выполнялось.

Источник отметок «стенд, 14.11.2026» — отчёт команды (Susanin_Handoff): привод испытывали
**без гусеничных ремней**, со старой прошивкой (таймаут 3 с), связь по Wi-Fi.

## Перед любым включением моторов

- [ ] Измерения из [AUDIT.md](AUDIT.md), раздел 9.3; выход DC-DC 5.0–5.2 В.
- [ ] Каждый аккумулятор заряжен (методичка BOTS: выше 3.7 В на элемент).
- [ ] Рядом человек, готовый выключить питание выключателем на плате.
- [ ] После 30 с работы — проверить температуру TB6612.
