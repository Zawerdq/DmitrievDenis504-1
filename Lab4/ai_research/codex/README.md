# Lab4 · Динамический массив и сравнение решений

Начните с [отчёта по лабораторной](REPORT.md), чтобы разобраться в работе контейнера и четырёх графиках. В [рецензии](REVIEW.md) разобраны семинарский Journal, исходное решение Fable 5.2 и версия Codex. Там же приведены пятый график, время работы и известный расход лимита.

## Как читать файлы

| Файл | Для чего открыть |
|---|---|
| [subvector.hpp](subvector.hpp) | Весь контейнер Codex для `int`. Начните с `push_back`, затем проследите выбор ёмкости в `Growth::next` и выделение памяти в `resize`. |

| [compare.cpp](compare.cpp) | Один цикл добавления для трёх исходных реализаций. При сборке выбирается один контейнер. |

| [plot.py](plot.py) | Пересчёт медиан и построение графиков из готовых CSV. |
| [Исходное решение Fable](../../README.md) | Код, пояснения и результаты первого автора лежат уровнем выше. Для повторения общего опыта нужен также исходный архив семинара `Sem8.zip`. |

[std_constructors.csv](data/std_constructors.csv) читается как таблица. Каждая строка содержит имя конструктора, размер, ёмкость и значения элементов. В обоих файлах времени единица измерения — секунда. В `growth.csv` столбец `growths` считает запросы увеличения ёмкости, `address_changes` — смены адреса уже существующего блока, `prefix_elements` — суммарную длину заполненных префиксов при таких сменах.

## Как повторить

Из этой папки, с GCC для C++20, Python 3 и Matplotlib:

```bash
python3 run.py --journal "/путь/к/Sem8.zip"
```

Без `--journal` выполняется самостоятельная лабораторная с первыми четырьмя графиками. Опция `--measure-only` создаёт CSV без зависимости от Matplotlib. Уже сохранённые пять рисунков можно перестроить одной командой:

```bash
python3 plot.py --comparison
```

В PowerShell подходит команда `python` вместо `python3`. Для опубликованной серии измерения запускались в Ubuntu под WSL2, графики строились из этих CSV в Windows. Повторный запуск измерений обновляет данные в этой папке. Скрипт извлекает из архива только `container.h` и `container.cpp` в локальный каталог сборки `build/`.
