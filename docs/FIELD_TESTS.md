# Испытания на реальном роботе

Ни один пункт этого документа **ещё не выполнялся**. Отмечайте результат и дату; до тех пор
компонент считается проверенным только на эмуляторе.

## Перед любым включением моторов

- [ ] Измерения из [AUDIT.md](AUDIT.md), раздел 9.3, выполнены; выход DC-DC 5.0–5.2 В.
- [ ] Каждый аккумулятор заряжен (методичка BOTS: выше 3.7 В на элемент).
- [ ] Робот стоит на подставке, гусеницы в воздухе.
- [ ] Рядом человек, готовый выключить питание выключателем на плате.
- [ ] После 30 с работы — проверить температуру TB6612. Горячо держать палец → стоп, разбираться.

## Этап 3. Связь (моторы не включаются)

| № | Действие | Ожидание | Результат |
|---|---|---|---|
| 3.1 | `python3 scripts/esp32_probe.py --seconds 30` | связь держится, переподключений 0, задержка < 100 мс | |
| 3.2 | `python3 scripts/esp32_probe.py --led-blink` | светодиод ESP32 мигает раз в 0.5 с | |
| 3.3 | во время 3.1 выключить питание ESP32 | «не отвечает» не позже чем через 1.5 с; после включения — связь восстановилась сама | |

## Этап 4. Движение (на подставке)

| № | Действие | Ожидание | Результат |
|---|---|---|---|
| 4.1 | `esp32_probe.py --drive forward --duty 0.3 --seconds 1 --robot-is-on-stand` | обе гусеницы вперёд; иначе править `invert_*` / `swap_sides` | |
| 4.2 | то же с `back`, `left`, `right` | назад; левый поворот (правая вперёд, левая назад); правый поворот | |
| 4.3 | `ros2 launch susanin_bringup robot.launch.py` + teleop | вперёд/назад/повороты, плавный разгон | |
| 4.4 | отпустить клавиши | останов не позже чем через ~1 с | |
| 4.5 | `/susanin/e_stop` = true во время движения | немедленный останов; команды не проходят до `false` | |

## Этап 5. Надёжность (сначала на подставке, затем на полу на малой скорости)

| № | Действие | Ожидание | Результат |
|---|---|---|---|
| 5.1 | во время движения закрыть teleop (Ctrl+C) | останов ≤ 1 с | |
| 5.2 | во время движения `kill -9` узла управления | останов ≤ 1 с (сторожевой таймер моста), launch перезапускает узел | |
| 5.3 | во время движения `kill -9` моста | останов через **до 3 с** (таймаут прошивки, проблема П1) | |
| 5.4 | во время движения отключить Wi-Fi на Pi (`nmcli connection down bot5`) | то же: до 3 с | |
| 5.5 | перезагрузить ESP32 кнопкой RST | моторы стоят; связь восстанавливается; движение не возобновляется рывком | |
| 5.6 | 10 минут езды с разворотами | TB6612 и DC-DC не перегреваются, ESP32 не перезагружается | |

Пункты 5.3 и 5.4 — основание для правок прошивки Ф1–Ф2. Если прошита
[firmware/susanin_esp32](../firmware/README.md), ожидание в них — останов ≤ 0.5 с, и сначала
выполняется таблица «Проверка после прошивки» из firmware/README.md.

## Этап 4 на полу

Только после успешных этапов 3–5 на подставке. Начинать с `max_duty: 0.4`, свободное место
не менее 2 м во все стороны.
