## ROS 2 в контейнере

14.11.2026, образ `ros:jazzy-ros-base` (Ubuntu 24.04, Python 3.12, websocket-client 1.7.0,
websockets 10.4 — версии из apt, те же, что будут на Raspberry Pi с Ubuntu 24.04),
`scripts/ros_smoke_test.sh`:

* `colcon build` — 3 пакета собраны;
* `colcon test` — 1743 теста, 0 ошибок (повторено после добавления тестов вариантов прошивки);
* запуск `robot.launch.py fake_esp32:=true`: связь, вперёд, останов без `/cmd_vel`, назад,
  поворот влево и вправо, аварийный останов и его снятие — все проверки пройдены.

Не проверено: архитектура arm64 (Raspberry Pi), ROS 2 Humble, реальная ESP32.

Ошибки, найденные этими проверками и исправленные:

* мост не закрывал TCP-сокет, если соединение закрывала ESP32 (утечка при перезагрузке ESP32);
* подписка на `susanin/e_stop` требовала QoS transient local, из-за чего обычная команда
  `ros2 topic pub` не могла подать аварийный останов.

## Особенности, о которых нужно помнить

* Флаги `invert1/invert2` прошивки меняются кнопками веб-страницы и живут до перезагрузки
  ESP32. Если их переключили с телефона, направление движения через ROS тоже изменится.
  Полярность моторов для ROS задаётся в YAML (`invert_left`, `invert_right`, `swap_sides`).
* Команда скорости ниже порога страгивания выполняется на `min_duty`: очень медленно ехать
  робот не может (нет обратной связи по скорости).
* Силовой ключ GPIO15 (`fire`) из ROS не управляется намеренно: нагрузка не известна.
